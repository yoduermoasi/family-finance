# Family Finance — How to Run

Open two terminal tabs:

**Tab 1 — Backend**
```
cd ~/family-finance/backend
npm run dev
```
Runs on http://localhost:3001

**Tab 2 — Frontend**
```
cd ~/family-finance/frontend
npm run dev
```
Opens http://localhost:5173

---

Data is stored in: `backend/data/db.json`
